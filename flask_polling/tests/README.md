# الاختبارات

تكتب الاختبارات مع كل مرحلة، لا بعد اكتمال المشروع. لا يُقبل مسار تصويت تشغيلي من دون اختبار نجاح واختبار فشل واختبار إساءة استخدام مناسب.

| المجلد | الغرض |
|---|---|
| `unit/` | اختبار كل طبقة أو وظيفة مستقلة |
| `integration/` | اختبار تعاون Flask والتشفير وSQLite |
| `security/` | اختبار CSRF والتكرار والتلاعب والتسريب |
| `e2e/` | اختبار السيناريو الكامل من إنشاء الاستطلاع إلى التقرير |
