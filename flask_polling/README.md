# صَوِّت — هيكل Flask المبسّط

> هذا المجلد هو **هيكل فقط**. لا يحتوي على كود تشغيل، أو مسارات، أو جداول، أو خوارزميات منفذة.

## الطبقات

| الطبقة | المجلد | المسؤولية لاحقًا |
|---|---|---|
| قلب النظام | `src/core/` | قواعد الاستطلاع والرموز والبطاقات والتدقيق |
| التشفير | `src/crypto/` | التشفير التشغيلي والمختبر الأكاديمي والمفاتيح |
| Flask | `src/web/` | إنشاء التطبيق، المسارات، الجلسات، والحماية الويبّية |
| الواجهة | `src/ui/` | القوالب والملفات الثابتة فقط |
| البيانات | `src/data/` | SQLite والنماذج والمستودعات |
| الاختبارات | `tests/` | اختبارات الوحدة والتكامل والأمان والتدفق الكامل |
| التوثيق | `../docs/` | الفكرة والنطاق والتحليل والمتطلبات والمعمارية |

## قواعد مختصرة

1. لا تُكتب قواعد العمل داخل طبقة Flask أو الواجهة.
2. لا تُستخدم خوارزميات المختبر في مسار التصويت التشغيلي.
3. لا تستورد طبقة `core` Flask أو SQLite أو أي تفاصيل واجهة.
4. لا يوضع أي مفتاح أو رمز خام أو بطاقة تصويت في السجلات.
5. تُضاف الوظائف طبقةً طبقة وبحسب مواصفة المتطلبات المعتمدة.

## أوامر التطوير

> هذه الأوامر موثقة الآن، وتصبح قابلة للتشغيل تباعًا عند اكتمال ملفات Flask والاختبارات في الخطوات اللاحقة.

| الأمر | الاستخدام |
|---|---|
| `pip install -e ".[dev]"` | تثبيت المشروع وحزم التطوير من `pyproject.toml` |
| `python run.py` | تشغيل Flask محليًا بعد تنفيذ الخطوة 1.4 |
| `pytest` | تشغيل الاختبارات بعد تنفيذ الخطوة 1.5 |
| `ruff check .` | فحص جودة Python |
| `ruff format --check .` | التحقق من تنسيق الملفات |
