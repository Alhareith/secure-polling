# طبقة Flask

هذه الطبقة تربط المتصفح بالنظام، ولا تنفذ قواعد التصويت أو SQL أو التشفير بنفسها.

| الملف | الاستخدام لاحقًا |
|---|---|
| `app.py` | إنشاء تطبيق Flask وإعداداته العامة |
| `routes.py` | مسارات المشرف والمصوّت والمراجع والمختبر |
| `auth.py` | دخول المشرف والجلسة والحماية من CSRF |
