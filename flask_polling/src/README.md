# مجلد المصدر

يحوي هذا المجلد طبقات المشروع فقط. كل طبقة لها مسؤولية واحدة، ولا تتجاوزها إلى طبقة أخرى بصورة مباشرة إلا عبر واجهة واضحة.

| المجلد | المعنى |
|---|---|
| `core` | ما الذي يجب أن يحدث في الاستطلاع؟ |
| `crypto` | كيف تحمى البطاقات والرموز والتقارير؟ |
| `web` | كيف يستقبل Flask طلبات المتصفح ويعيد الاستجابة؟ |
| `ui` | كيف تظهر الصفحات للمشرف والمصوّت والمراجع؟ |
| `data` | كيف تحفظ البيانات وتستعاد من SQLite؟ |
