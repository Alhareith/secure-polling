# قلب النظام

هذه الطبقة تصف **قواعد المشروع** فقط، ولا تعرف Flask أو SQLite أو HTML.

| الملف | المسؤولية لاحقًا |
|---|---|
| `polls.py` | حالات الاستطلاع وقواعد نشره وإغلاقه وعدّه |
| `tokens.py` | حالة الرمز وقواعد استخدامه لمرة واحدة |
| `audit.py` | أحداث التدقيق وسلسلة البصمات وقواعد التقرير |
