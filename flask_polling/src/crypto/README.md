# طبقة التشفير

تفصل هذه الطبقة بين الحماية التشغيلية والمختبر الأكاديمي.

| الملف | الاستخدام لاحقًا |
|---|---|
| `secure.py` | AES-GCM وHMAC وSHA-256 وRSA-PSS للمسار التشغيلي |
| `keys.py` | تحميل المفاتيح وإصداراتها من خارج قاعدة البيانات |
| `lab.py` | خوارزميات المقرر والتجارب فقط، بلا وصول إلى البيانات الحقيقية |

> لا تستخدم خوارزميات `lab.py` لحماية التصويت الحقيقي.
