# طبقة البيانات

هذه الطبقة هي الطريق الوحيد إلى SQLite لاحقًا. لا تستدعي صفحات الويب أو طبقة التشفير قاعدة البيانات مباشرة.

| الملف | المسؤولية لاحقًا |
|---|---|
| `db.py` | فتح وإغلاق الاتصال وإعداد المعاملات |
| `models.py` | تعريف الجداول والنماذج فقط |
| `repo.py` | عمليات الحفظ والاسترجاع بصورة واضحة ومحدودة |
