# طبقة الواجهة

تضم هذه الطبقة **القوالب** و**الملفات الثابتة** فقط. لا توضع فيها قواعد التصويت أو الاستعلامات أو خوارزميات التشفير.

| المجلد | الاستخدام لاحقًا |
|---|---|
| `templates/` | صفحات Jinja للمشرف والمصوّت والمراجع والمختبر |
| `static/` | التنسيق والصور وملفات JavaScript الصغيرة عند الحاجة |
